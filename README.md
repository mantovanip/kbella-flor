## Desenvolvimento local

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
```

## Publicação

O projeto utiliza **GitHub Pages**. Todo push na branch `main` executa o workflow:

```
GitHub
  ↓
GitHub Actions
  ↓
npm install
  ↓
npm run build
  ↓
dist
  ↓
GitHub Pages
```

O `vite.config.js` utiliza:

```js
base: "/kbella-flor/"
```
